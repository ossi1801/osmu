# Lets build a crossplatform (windows/linux, macos is extra) 2D/3D a game engine/graphical editor called 'OSMU'(overengineered system manipulation userinterface)

## Core features
* UI like unity, godot, you know. inspector, graphical live viewing, node editing etc..
* Own strongly typed scripting language (.osmu files) that resembles c# in its syntax
* Events, data searching (querying data) should be done very easily with minimal code or nodes.
* Graphical node like editor wehere basic stuf can be done like connecting signals etc. (think blender nodes)
* Graphical node lines should automatically grouped so that it looks clean.
* Game engine itself (source code) is golang

# Main focus IS NOT to do a text editor. there are multiple good text editors, but we need a compiler of some sorts for the osmu files that can detect syntax erros and mby lsp
